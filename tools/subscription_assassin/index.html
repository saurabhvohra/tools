Subscription Assassin 🎯

Stop wasting hours trying to find the "Cancel" button. Let an AI-powered agent do the dirty work for you.

# Deploy the assassin to any service $ assassin --target "Adobe" --email "user@example.com"
# Output: 🕵️ Assassin deployed to Adobe... ✅ Navigated to Billing Settings ✅ Bypassed "Stay for 50% discount" popup ✅ Bypassed "Are you sure?" survey 🎯 Target eliminated. Subscription cancelled.

1. Install the Tool

This is a local automation tool powered by Playwright. You need Python installed on your machine.

pip install playwright-assassin

2. Choose Your Target

The assassin currently supports **Adobe, Netflix, NYT, Amazon Prime, and LinkedIn**.

3. Execute

Run the command and watch the AI navigate the dark patterns for you in a controlled browser window.
